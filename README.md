# NEXDATA BSC Intelligence 360°

Aplicación **independiente**. No reemplaza la app comercial ni el dashboard del plan estratégico.

## Instalación en un nuevo repositorio
1. Crea el repositorio `nexdata-bsc-independiente`.
2. Sube `NEXDATA_BSC_INDEPENDIENTE.py` y `requirements.txt` a la raíz.
3. En Streamlit Community Cloud crea una app nueva apuntando a `NEXDATA_BSC_INDEPENDIENTE.py`.
4. Opcional para IA generativa: en **App settings → Secrets**, configura `OPENAI_API_KEY = "TU_CLAVE"` y opcionalmente `OPENAI_MODEL = "gpt-4.1-mini"`. **Nunca publiques la clave en GitHub.** El proveedor puede cobrar por uso.

## Modelo
BSC clásico: Financiera, Clientes, Procesos internos, Aprendizaje y crecimiento. La app desdobla la última en RR. HH. y Capacitación por fines de presentación; no son cinco perspectivas clásicas.

## Transparencia
Los KPI y las metas son simulaciones y propuestas académicas. La API del Banco Mundial aporta contexto, no prueba demanda. La IA generativa funciona solo con API configurada; sin ella hay reglas automatizadas.
