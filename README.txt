# NEXDATA — Dashboard Estratégico + BSC 360

1. Descomprime el paquete.
2. Sube el .py al repositorio separado `nexdata-plan-estrategico`.
3. En Streamlit Cloud, selecciona como Main file path `NEXDATA_Dashboard_Estrategico_IA_BSC_360.py`, o renómbralo para que coincida con el nombre del script ya configurado.
4. Mantén `requirements.txt` en la raíz.
5. La pestaña «✧ BSC Intelligence» contiene anillos, radar, Sankey, treemap, burbujas y una consulta online al Banco Mundial.

Los KPI de NEXDATA son simulaciones académicas; la API del Banco Mundial suministra estadísticas externas. Las recomendaciones son reglas automatizadas, no IA generativa.
